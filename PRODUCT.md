# Producto: Faro

## Registro
**Producto** (herramienta operativa, no una página de marketing). El diseño sirve a la tarea.

## Usuario y tarea
Una persona que acaba de desplegar el entorno (estudiante, docente, operador) y necesita
saber **en un vistazo si cada capa responde** y **comprobar que una escritura llega hasta MySQL**.
Entra desde un portátil o el móvil, con prisa y casi siempre para confirmar algo concreto.

## Propósito
Mostrar el recorrido real de una petición: proxy → web → API → base de datos, con su estado
medido, y dejar que el usuario mande una "señal" que atraviese todo el trayecto.

## Personalidad de marca
Preciso, sereno, marinero. Un faro no presume: avisa. Voz directa en español, frases cortas,
sin jerga innecesaria ni exclamaciones.

## Principios
1. **El estado es el titular.** La respuesta a "¿funciona?" ocupa lo más grande de la pantalla.
2. **Nada decorativo.** El único movimiento es el haz de luz, y solo ocurre como respuesta a una acción.
3. **Un acento.** El ámbar de la lámpara se reserva para el haz, la acción principal y la selección.
4. **El color nunca va solo.** Cada estado también se escribe con palabras.

## Anti-referencias (lo que Faro NO debe parecer)
Dashboard SaaS genérico de tarjetas con iconos, fondo negro con acento neón, degradados morados,
beige "editorial" con serif cursiva, cuadrículas de métricas gigantes con etiquetas diminutas.
